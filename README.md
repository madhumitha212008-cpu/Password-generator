# Password Generator

## About
Password Generator is a simple project that generates random passwords to help users create stronger passwords for their accounts.

## Features
- Generate random passwords
- Choose password length
- Create passwords using letters, numbers, and special characters
- Simple and easy to use

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

bash
python password_generator.py
